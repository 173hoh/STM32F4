# 🌿 智慧水培系统

基于 **STM32F103CC8T6** 的多传感器智能水培控制平台，实现对植物水培环境的实时监测与自动化调控。

## 📦 项目概述

本系统整合了多个环境传感器，配合 PID 控制算法和 MOSFET 开关控制，实现对水温、光照、湿度、PH 值、浊度等关键参数的精准管理。适用于智能农业、水培实验与教育教学等场景。

## 🧠 项目架构

- **主控芯片**：STM32F103C8T6（ARM Cortex-M3 内核）
- **开发方式**：裸机编程
- **控制策略**：PID 控温，MOS 管开关驱动
- **结构特点**：
  - 多传感器集成
  - 实时控制
  - 结构清晰，便于扩展

## 🛠️ 硬件列表

| 模块            | 功能描述               |
|-----------------|------------------------|
| STM32F103CC8T6  | 主控芯片               |
| DS18B20         | 水温传感器（数字）     |
| DHT11           | 环境温湿度传感器       |
| PH 模拟传感器   | 检测水体酸碱度         |
| 浊度传感器      | 检测水体洁净程度       |
| TEMT6000        | 光照强度传感器         |
| MOSFET 模块     | 控制加热棒开关         |
| 加热棒          | 提升水体温度           |
| 电源/继电模块   | 为系统供电与控制       |

## ⚙️ 软件功能

- 🌡️ **PID 控温**：根据 DS18B20 采集的温度值，动态调节加热棒工作状态；
- 💡 **光照监测**：使用 TEMT6000 实时监控环境光强；
- 💧 **PH 与浊度**：辅助监测营养液质量，提供稳定水培环境；
- 📈 **状态调度**：采用定时中断和状态机管理采集与控制逻辑；
- 🔌 **MOS 管控制**：通过 PWM 或 GPIO 控制加热棒启停，响应 PID 输出。
