# 🌿 STM32 智能水培系统（PID 控温 + 微信小程序监控）

本项目基于 STM32 单片机，通过 PID 控制加热棒实现水温调节，并通过多种传感器采集环境数据（温度、湿度、pH、浊度、水位），配合 Python 脚本与阿里云短信 API 实现远程环境报警。用户可通过微信小程序实时查看水培环境状态，是一个完整的智慧农业 / 水培控制系统方案。

---

## 🧰 1. 硬件准备

- STM32F103C8T6 最小系统板
- 温湿度传感器（如 DHT22）
- PH 传感器模块
- 浊度传感器
- 水位传感器
- MOSFET 控制模块
- 加热棒
- 蓝牙模块（可选）
- 电源模块 / 稳压模块
- 杜邦线若干

---

## 📱 2. 软件系统与功能

### ✅ 微信小程序端实时监控
- 实时查看以下参数：
  - 🌡️ 温度
  - 💧 湿度
  - 🧪 pH 值
  - 🌫️ 浊度
  - 📏 水位高度
- 页面交互清晰，可移动访问、远程管理

### ✅ PID 控制水温
- STM32 裸机程序实现 PID 算法
- 控制 MOSFET 打开/关闭加热棒
- 保持水温在设定范围，稳定性高

### ✅ Python 阿里云报警系统
- 当环境参数异常（如水温过高、pH 失衡、水位过低等）时：
  - 自动触发 Python 脚本
  - 通过阿里云短信 API 发送预警消息至绑定手机号
- 警报信息内容可自定义

## 🔍 4. 使用说明

1. 在 Keil / STM32CubeIDE 中编译并烧录 PID 控制程序至 STM32
2. 连接各类传感器与加热棒，MOSFET 控制模块接负载
3. 运行 Python 脚本监听数据、触发短信（已集成短信 API）
4. 打开微信小程序，绑定设备后查看各类实时环境数据
