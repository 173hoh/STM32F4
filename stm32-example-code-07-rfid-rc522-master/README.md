# 📚 STM32 智慧书房项目（RC522 RFID + 蓝牙 + 环境监测）

本项目基于 STM32F103C8T6 最小系统板，集成了 RFID 卡识别、蓝牙推送、环境监测（温湿度、光照、烟雾）、OLED 实时显示与自动响应控制（蜂鸣器、风扇、WS2812 灯光提示）等功能，适用于智慧书房等物联网场景。

---

## 🧰 1. 硬件准备

- RC522 RFID 模块
- STM32F103C8T6 最小系统板
- OLED 屏幕（SSD1306）
- 温湿度传感器（如 DHT11 / DHT22）
- 光照传感器（如光敏电阻）
- 烟雾传感器（如 MQ-2）
- WS2812 RGB LED 灯
- 蜂鸣器
- 风扇
- 蓝牙模块（如 HC-05 / HM-10）
- 杜邦线若干

---

## 💡 2. 系统功能简介

### ✅ RFID识别 + 蓝牙推送
- 将RC522读取的卡片 ID，通过蓝牙实时推送至上位机（蓝牙调试助手）界面

### ✅ OLED 实时环境信息显示
- 显示当前：
  - 温度
  - 湿度
  - 光照强度
  - 烟雾浓度

### ✅ 联动响应控制逻辑
- **温湿度或烟雾异常时**：
  - 蜂鸣器报警
  - 启动风扇
  - WS2812 亮红灯警示

- **光照不足时**：
  - WS2812 启动白光补光

---

## 🔍 3. 使用说明

1. 使用 Keil 或 STM32CubeIDE 编译工程，确保无警告或错误
2. 烧录程序到 STM32F103C8T6
3. 硬件连接无误后通电运行
4. 使用串口助手或蓝牙调试助手查看实时推送数据
5. 将 RFID 卡靠近 RC522 模块进行刷卡测试

---

## 🖼️ 4. 现象演示

- OLED 显示实时温湿度、光照、烟雾浓度
- 蓝牙上位机接收到卡号、传感器数据
- 当传感器值异常时，自动启动相关响应装置（如蜂鸣器、风扇、RGB 灯）
